# Corpus Zarma (Djerma)

Ce répertoire contient les données, les scripts et les métadonnées pour le projet d'Assistant Intelligent en Zarma (Djerma).

## Structure des répertoires

- `raw/` : Données brutes (texte, audio, vidéo).
- `cleaned/` : Données nettoyées (monolingues, parallèles, conversations).
- `metadata/` : Métadonnées associées aux données du corpus.
- `tokenizer/` : Données et modèles liés à la tokenisation.
- `train/` : Ensemble de données pour l'entraînement.
- `validation/` : Ensemble de données pour la validation.
- `test/` : Ensemble de données pour les tests.
