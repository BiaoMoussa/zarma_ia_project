# Cours — Apprentissage de l'IA à travers le projet Zarma

Ce dossier contient les leçons rédigées au fur et à mesure de l'avancement du projet.

## Contenu

| # | Cours | Contenu |
|---|---|---|
| 1 | [Tokenisation](01-tokenisation.md) | BPE, vocabulaire, tokens spéciaux, tokenizer spécialisé vs générique |
| 2 | [Fine-tuning et LoRA](02-fine-tuning-lora.md) | Fine-tuning, LoRA, QLoRA, Unsloth, choix du modèle de base |

## Organisation

Chaque cours est autonome : tu peux le relire indépendamment des autres. Les liens entre cours sont indiqués quand un concept évoqué est détaillé ailleurs.

Les cours sont rédigés pour être **relus hors session** — pas besoin d'avoir le code sous les yeux pour comprendre.
